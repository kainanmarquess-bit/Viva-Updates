# Viva Updates

Repositório público de distribuição de versões oficiais do aplicativo Viva.

- `manifest.json`: manifesto público consultado pelo aplicativo.
- APKs oficiais: publicados como assets de GitHub Releases.

Este repositório não contém código-fonte, credenciais ou tokens.

## Manifesto

O manifesto começa sem uma versão publicada. Ele será atualizado automaticamente pelo workflow autorizado do repositório privado `Viva` após a configuração do acesso de publicação.
